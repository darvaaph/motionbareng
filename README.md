# motionbareng

Website kelas online **motionbareng**: belajar bikin video motion (explainer & shorts) pakai Claude Code + ElevenLabs.

- Website (yang dipublikasikan): [`Company Profile/website/`](Company%20Profile/website/)
  - `index.html`: halaman link bio
  - `kelas.html`: halaman jualan
  - `pengaturan.js`: link checkout, harga, kontak, contoh karya
- Peta folder lengkap: [`Company Profile/README.md`](Company%20Profile/README.md)

Website ini statis (HTML + CSS + JS biasa), tanpa proses build.
Saat deploy di Vercel/Netlify, atur **Root Directory** ke `Company Profile/website`.
